# نسخه ۷.۲.۱ — Windows Edition

- تمرکز کامل بسته انتشار بر ویندوز ۱۰ و ۱۱ نسخه ۶۴ بیتی.
- افزودن آیکون رسمی Windows و اطلاعات نسخه به فایل اجرایی.
- ساخت خودکار نسخه Portable و Setup از طریق `build_setup_windows.bat`.
- نصب به‌صورت per-user بدون نیاز به دسترسی Administrator.
- نگهداری دیتابیس و پیوست‌ها در `%LOCALAPPDATA%\JavanroodNeighborhoodManagement`.
- پشتیبان‌گیری خودکار از اطلاعات موجود پیش از نصب یا ارتقا.
- تولید SHA-256 برای خروجی‌های Windows.
- افزودن کنترل انتشار برای جلوگیری از ورود کدهای موقت یا فایل ناقص به نسخه نهایی.
