# سامانه مدیریت محله‌محور جوانرود — نسخه ویندوز ۷.۲.۱

این بسته فقط برای **Windows 10/11 نسخه ۶۴ بیتی** آماده شده است.

## استفاده نهایی

خروجی رسمی شامل دو نوع بسته است:

- `JavanroodNeighborhoodManagement_Setup_7.2.1_Windows_x64.exe` برای نصب استاندارد
- `JavanroodNeighborhoodManagement_7.2.1_Windows_x64_Portable.zip` برای اجرای پرتابل

## محل اطلاعات کاربران

در نسخه نصب‌شده، دیتابیس، گزارش‌ها، پیوست‌ها و نسخه‌های پشتیبان در مسیر زیر قرار می‌گیرند:

```text
%LOCALAPPDATA%\JavanroodNeighborhoodManagement
```

این پوشه هنگام به‌روزرسانی یا حذف برنامه پاک نمی‌شود.

## پشتیبان‌گیری هنگام نصب نسخه جدید

نصب‌کننده پیش از ارتقا، از دیتابیس و پیوست‌های موجود نسخه پشتیبان تهیه می‌کند. بکاپ در مسیر زیر ذخیره می‌شود:

```text
%LOCALAPPDATA%\JavanroodNeighborhoodManagement\preinstall_backups
```

اگر پشتیبان‌گیری کامل نشود، نصب متوقف خواهد شد.

## ساخت EXE و Setup روی ویندوز

پیش‌نیازها:

1. Windows 10 یا Windows 11 نسخه ۶۴ بیتی
2. Python 3.11 نسخه ۶۴ بیتی
3. Inno Setup 6 برای ساخت فایل Setup

سپس فقط این فایل را اجرا کنید:

```text
build_setup_windows.bat
```

خروجی‌ها در پوشه `release` ساخته می‌شوند و برای هر فایل، SHA-256 نیز تولید می‌شود.

## اجرای سورس روی ویندوز

برای اجرای مستقیم سورس و نصب خودکار وابستگی‌ها:

```text
run_windows.bat
```

## ورود اولیه

- نام کاربری: `admin`
- رمز عبور: `admin123`

پس از نخستین ورود، رمز پیش‌فرض باید تغییر کند.

## نکته مهم ارتقا

فایل‌های نسخه قدیمی Python را روی نسخه جدید کپی نکنید. برای نسخه نصب‌شده فقط Setup جدید را اجرا کنید. برای نسخه پرتابل، پوشه `data` قبلی را نگه دارید و پوشه برنامه را کامل جایگزین کنید.


## شورای اجتماعی جامع — نسخه 7.2.15

از داشبورد، گزینه «شورای اجتماعی» را باز کنید. برای هر بلوک پرونده مستقل شورا به‌صورت خودکار ایجاد می‌شود. اعضای شورای محله، معتمدان، مسئولان اماکن و نمایندگان کمیته‌های شش‌گانه با دکمه همگام‌سازی، بدون حذف اعضای دستی به شورا اضافه می‌شوند.

بخش‌ها: داشبورد اجتماعی، اعضا، جلسات، مسائل اجتماعی، ارجاعات، مصوبات، برنامه‌های عملیاتی و گزارش‌ها. پرونده‌های دارای سطح «محرمانه» یا «فقط مدیر سیستم» بر اساس نقش کاربر محدود می‌شوند.

## نسخه 7.2.16 — فرم‌های اسکرول‌دار و دسته‌بندی پویا

- دسته‌های پیش‌فرض و سفارشی در ثبت، ویرایش، گزارش و جستجو حفظ می‌شوند.

## نسخه 7.2.17 — گزارش‌های نموداری میله‌ای شورای اجتماعی
- تب مستقل «گزارش‌های نموداری» با پنج گزارش مدیریتی اضافه شده است.
- نمودارها شامل دسته‌بندی آسیب‌های اجتماعی، مقایسه بلوک‌ها، عملکرد کمیته‌های شش‌گانه، وضعیت مصوبات و وضعیت برنامه‌های عملیاتی هستند.
- فیلترهای بلوک، کمیته، وضعیت، از تاریخ و تا تاریخ روی گزارش‌ها اعمال می‌شوند.
- جدول عددی هر نمودار زیر آن نمایش داده می‌شود.
- نمودار جاری به PNG و مجموعه هر پنج نمودار به Word و PDF قابل خروجی است.
- موتور نمودار با Qt داخلی اجرا می‌شود و وابستگی جدیدی به بسته نصب اضافه نشده است.

## نسخه 7.2.21: مدیریت کلاینت‌های آفلاین

در داشبورد ادمین بخش «مدیریت کلاینت‌ها» اضافه شده است. این بخش درخواست دستگاه `.jrr` را دریافت می‌کند، فایل فعال‌سازی یا تمدید `.jra` می‌سازد و فایل خروجی رمزنگاری‌شده `.jrcx` را پس از کنترل امضا، مجوز، تاریخ، بلوک، کمیته و تکراری‌بودن وارد می‌کند.

کلیدهای خصوصی تبادل فایل در پوشه داده‌های برنامه زیر `security/client_exchange` ساخته می‌شوند و داخل سورس توزیع نمی‌شوند. نگهداری نسخه پشتیبان امن از این پوشه ضروری است.


## نسخه 7.3.2 — برآورد جمعیت بلوک‌ها

از داشبورد گزینه «برآورد جمعیت» را باز کنید. داده‌های WorldPop یا GHSL را در قالب CSV/GeoJSON وارد کنید؛ GeoTIFF نیز با نصب اختیاری rasterio پشتیبانی می‌شود. سپس برای هر بلوک تعداد واحد مسکونی، نرخ سکونت، بعد خانوار و کنتورهای فعال را ثبت و محاسبه را اجرا کنید.

خروجی شامل جمعیت نهایی، بازه حداقل و حداکثر، تعداد خانوار، تراکم نفر در کیلومترمربع و سطح اطمینان است. نمونه فایل ورودی در `sample_data/population_cells_template.csv` قرار دارد. این خروجی برآورد آماری است و جایگزین آمار رسمی سرشماری یا داده‌های ثبتی نیست.
