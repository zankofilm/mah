# نسخه ۷.۲.۰ — مرکز عملیات یکپارچه

- گردش کامل مصوبه و اقدام تا نتیجه نهایی
- کارتابل عمومی ارجاعات با ثبت مشاهده و پاسخ
- پرونده جامع بلوک و خروجی HTML/CSV
- مدیریت اسناد و پیوست‌های پرونده‌های اجرایی
- داشبورد پیشرفته پرونده‌های باز، معوق و سررسیدها
- رتبه‌بندی عملکرد دستگاه‌ها و بلوک‌ها
- یکپارچگی با پشتیبان‌گیری، مرکز سلامت و بسته نصب ویندوز
- مهاجرت غیرمخرب مصوبات و اقدامات قبلی به مرکز پیگیری
