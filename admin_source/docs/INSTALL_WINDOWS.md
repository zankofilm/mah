# راهنمای نصب و ساخت نسخه Windows x64

## نصب برای کاربر نهایی

فایل Setup را اجرا کنید. برنامه برای همان حساب کاربری ویندوز در مسیر زیر نصب می‌شود و نیاز به دسترسی Administrator ندارد:

```text
%LOCALAPPDATA%\Programs\JavanroodNeighborhoodManagement
```

اطلاعات عملیاتی در مسیر جداگانه زیر نگهداری می‌شوند:

```text
%LOCALAPPDATA%\JavanroodNeighborhoodManagement
```

به همین دلیل نصب نسخه جدید، حذف برنامه یا تغییر پوشه نصب باعث حذف دیتابیس نمی‌شود.

## ارتقا

1. برنامه را ببندید.
2. Setup نسخه جدید را اجرا کنید.
3. نصب‌کننده پیش از ارتقا از دیتابیس و پوشه پیوست‌ها بکاپ می‌گیرد.
4. برنامه را از میانبر دسکتاپ اجرا کنید.

## ساخت نسخه رسمی

### پیش‌نیازها

- Windows 10/11 x64
- Python 3.11 x64
- Inno Setup 6
- دسترسی اینترنت فقط برای نصب وابستگی‌های build در اجرای نخست

### فرمان ساخت

روی فایل زیر دوبار کلیک کنید:

```text
build_setup_windows.bat
```

اسکریپت به‌ترتیب این عملیات را انجام می‌دهد:

1. ساخت محیط مجزای build
2. نصب وابستگی‌ها
3. کنترل فایل‌های انتشار
4. کامپایل سورس‌ها
5. اجرای تست‌های خودکار
6. ساخت EXE با PyInstaller
7. ساخت ZIP پرتابل
8. ساخت Setup با Inno Setup
9. تولید SHA-256

### خروجی

فایل‌های نهایی در پوشه زیر قرار می‌گیرند:

```text
release
```

## محدودیت ساخت

PyInstaller امکان ساخت مستقیم EXE ویندوز از Linux یا macOS را ندارد. فرایند `build_setup_windows.bat` باید روی خود Windows اجرا شود.
