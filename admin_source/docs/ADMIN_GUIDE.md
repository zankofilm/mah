# راهنمای مدیر سامانه

- هر روز وضعیت هشدارهای داشبورد را بررسی کنید.
- بکاپ روزانه خودکار را کنترل و یک نسخه دوم روی حافظه یا مسیر شبکه امن نگهداری کنید.
- حساب‌های بلااستفاده را غیرفعال کنید؛ حساب مشترک نسازید.
- اطلاعات محرمانه را در درگاه عمومی منتشر نکنید.
- قبل از بروزرسانی نسخه، بکاپ پیش از مهاجرت را نگهداری کنید.
- برای ارسال خطا به پشتیبان، از «بسته پشتیبانی» استفاده کنید و تنها در مسیر امن گزینه افزودن دیتابیس را فعال کنید.
