# نسخه ۷.۱.۱۸

- بازگردانی ساختار صحیح شش کمیته تخصصی برای هر بلوک.
- نمایش هر شش کمیته به‌صورت کارت‌های واضح و قابل انتخاب.
- نمایش برجسته کمیته بازشده، وضعیت، اعضا، جلسات و مصوبات باز.
- حفظ استعلام کد ملی و پرونده مشترک اشخاص.
- حفظ گزارش‌های PDF، Excel، PowerPoint و پیش‌نمایش برای هر شش کمیته.
- مهاجرت غیرمخرب از نسخه تک‌کمیته‌ای؛ اطلاعات قبلی در کمیته عمران نگهداری می‌شود.
