# نسخه 7.1.0 — داشبورد مدیریتی واقعی

- جایگزینی سربرگ نامه‌ای داخل محیط برنامه با هدر سرمه‌ای کم‌ارتفاع نرم‌افزاری.
- طراحی داشبورد واقعی PyQt مطابق طرح تأییدشده.
- نمایش نقشه واقعی بلوک‌ها در مرکز داشبورد.
- نمایش کارت‌های آمار، درخواست‌ها، اقدامات، اعلان‌ها و پروژه‌ها با داده‌های دیتابیس.
- افزودن نوار دسترسی سریع به ماژول‌های اصلی.
- حفظ کامل سربرگ اداری فقط برای خروجی Word و PDF.
- بدون تغییر مخرب در دیتابیس.
