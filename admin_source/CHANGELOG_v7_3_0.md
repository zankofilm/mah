# نسخه ۷.۳.۰ — پایداری، امنیت و انتشار نهایی

## امنیت
- حذف رمز ثابت ادمین در اجرای واقعی و تولید رمز موقت تصادفی در فایل حفاظت‌شده.
- سیاست رمز قوی، قفل موقت حساب و ثبت رویدادهای امنیتی.
- رمزگذاری کلیدهای API پیامک و هوش مصنوعی با کلید محلی دستگاه.
- کنترل مجوز عملیات حساس در لایه منطق برنامه، علاوه بر رابط کاربری.

## پیام‌رسانی
- جلوگیری از ارسال تکراری با کلید idempotency پنج‌دقیقه‌ای.
- شمارش تلاش‌ها، توقف/ادامه عملیات، ارسال مجدد خطاها و ثبت وضعیت تحویل.
- حفظ تاریخچه کامل کمپین و پاسخ سرویس.

## معماری و کیفیت کد
- استخراج کاربران و احراز هویت به `database_users.py`.
- استخراج بکاپ و سازگاری امنیتی به `database_backup_security.py`.
- استخراج پرونده اشخاص به `database_people.py`.
- افزودن `database_hardening.py` و `security_service.py`.

## یکپارچگی داده
- وضعیت کیفیت داده برای پرونده اشخاص.
- حذف نرم، بازیابی، شناسایی رکورد تکراری و ادغام همراه با تاریخچه.
- مرکز کیفیت داده در ماژول حکمرانی داده.

## بکاپ و بازیابی
- بکاپ رمزگذاری‌شده با پسوند `.jrbak` و AES-GCM.
- نمایش سلامت و سن آخرین بکاپ.
- آزمون بازیابی آخرین بکاپ بدون جایگزینی دیتابیس اصلی.

## تجربه کاربری
- راهنمای شروع سریع داخل داشبورد.
- نمایش هم‌زمان سلامت دیتابیس و بکاپ در نوار وضعیت.
- بهبود ابزارهای کنترل پیام و بکاپ در رزولوشن‌های کوچک.

## انتشار
- تست جدید نسخه ۷.۳.۰.
- GitHub Actions ویندوز برای تست، ساخت EXE، نسخه Portable و Setup.
- اسکریپت Inno Setup برای نصب استاندارد ویندوز.
