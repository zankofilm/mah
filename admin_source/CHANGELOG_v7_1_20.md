# نسخه 7.1.20

- بازشدن خودکار اولین کمیته معتبر هر بلوک.
- حذف پیام مبهم «هنوز کمیته‌ای باز نشده است».
- نمایش حالت روشن برای نبود بلوک یا نبود کمیته.
- تضمین ایجاد و بارگذاری شش کمیته هنگام تغییر بلوک.
- یکسان‌سازی اندازه تمام صفحات اصلی با نمایش Maximized.
- گزارش‌ها، شورا، بلوک‌بندی و سایر ماژول‌ها هم‌اندازه داشبورد باز می‌شوند.
