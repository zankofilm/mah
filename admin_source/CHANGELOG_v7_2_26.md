# تغییرات نسخه ۷.۲.۲۶

- فعال‌سازی ماژول «ارسال پیام» در نوار دسترسی و کارت‌های داشبورد.
- انتخاب بلوک و گروه گیرندگان: شورای بلوک، کمیته‌های شش‌گانه و شورای اجتماعی.
- حذف خودکار شماره‌های تکراری و نامعتبر.
- تنظیمات API پیامک فقط برای مدیر سامانه.
- حالت آزمایشی بدون ارسال واقعی برای کنترل کامل گردش کار.
- ارسال واقعی از طریق API عمومی JSON.
- ثبت کمپین، نتیجه هر گیرنده، خطا، شناسه سرویس و تاریخ ارسال.
- سطح دسترسی مستقل messaging برای مدیران و کارشناسان مجاز.
