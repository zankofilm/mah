# کلاینت کمیته‌های محلات جوانرود 1.0.0

این برنامه کلاینت آفلاین و محدودشده سامانه مدیریت محلات جوانرود است.

## گردش فعال‌سازی

1. کاربر در اولین اجرا کد ملی خود را وارد و فایل `.jrr` تولید می‌کند.
2. مدیر فایل درخواست را در نسخه ادمین وارد می‌کند.
3. مدیر نام مسئول، بلوک، کمیته، نام کاربری، رمز اولیه و تاریخ انقضا را تعیین می‌کند.
4. مدیر فایل رمزنگاری و امضاشده `.jra` را صادر می‌کند.
5. کاربر فایل را همراه کد ملی خود در همان دستگاه نصب می‌کند.
6. پس از فعال‌سازی، ورود فقط با نام کاربری و رمز عبور مجاز است.

## محدودیت دسترسی

فقط پنل کمیته و بلوک ثبت‌شده در مجوز فعال است. سایر آیکون‌های کمیته غیرفعال‌اند. محدوده مجوز هنگام ساخت فایل خروجی و هنگام ورود در ادمین نیز دوباره کنترل می‌شود.

## اطلاعات قابل ثبت

- اعضای کمیته
- جلسات
- مسائل و درخواست‌ها
- مصوبات
- اقدامات اجرایی

رکوردهای محلی با AES-GCM رمزنگاری می‌شوند. فایل خروجی `.jrcx` با کلید عمومی ادمین رمزنگاری و با کلید دستگاه امضا می‌شود.

## انقضا و تمدید

در هر اجرا تاریخ شروع، پایان اعتبار و عقب‌بردن ساعت سیستم بررسی می‌شود. پس از انقضا، ورود و خروجی‌گیری مسدود است ولی داده‌های قبلی حذف نمی‌شوند. فایل تمدید فقط برای همان مجوز، کد ملی، دستگاه، بلوک و کمیته پذیرفته می‌شود.

## اجرا از سورس

```bat
install_dependencies.bat
run_windows.bat
```

## ساخت نسخه ویندوز

Python 3.11 x64 لازم است. سپس `build_windows.bat` را اجرا کنید.
