# فونت فارسی برای گزارش‌های PDF

برای اینکه متن فارسی در گزارش‌های PDF (تولیدشده در بخش «گزارش‌گیری») به‌درستی
نمایش داده شود، باید فونت رایگان و متن‌باز **Vazirmatn** را در همین پوشه قرار دهید.

## مراحل دانلود و نصب

1. به صفحه ریلیزهای رسمی فونت وزیرمتن در گیت‌هاب بروید:
   https://github.com/rastikerdar/vazirmatn/releases

2. آخرین نسخه را دانلود کنید (فایل zip، معمولاً با نامی شبیه `vazirmatn-vX.X.X.zip`).

3. فایل zip را باز کنید. داخل پوشه‌ای مثل `fonts/ttf/` دو فایل زیر را پیدا کنید:
   - `Vazirmatn-Regular.ttf`
   - `Vazirmatn-Bold.ttf`

4. این دو فایل را دقیقاً با همین نام‌ها در پوشه `fonts/` پروژه (کنار همین فایل README) کپی کنید:

```
javanrood_map_app/
└── fonts/
    ├── Vazirmatn-Regular.ttf   ← اینجا قرار دهید
    ├── Vazirmatn-Bold.ttf      ← اینجا قرار دهید
    └── README.md               (همین فایل)
```

5. برنامه را دوباره اجرا کنید. اگر فونت‌ها به‌درستی در جای خود باشند، هشدار مربوط به
   «فونت فارسی یافت نشد» در بخش گزارش‌گیری دیگر نمایش داده نمی‌شود و متن فارسی در
   فایل‌های PDF به‌درستی و خوانا نمایش داده خواهد شد.

## نکته

- اگر این فونت‌ها را اضافه نکنید، برنامه همچنان کار می‌کند و گزارش‌های PDF تولید
  می‌شوند، اما ممکن است حروف فارسی به‌درستی نمایش داده نشوند (چسبیده نبودن حروف یا
  ترتیب نادرست).
- گزارش‌های Excel (فرمت xlsx) از این محدودیت متأثر نیستند و همیشه فارسی را به‌درستی
  نمایش می‌دهند، چون از فونت‌های سیستم‌عامل خود کاربر (در Excel یا Google Sheets)
  استفاده می‌کنند.
